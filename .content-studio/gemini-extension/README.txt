LOCAL CONTENT STUDIO — GEMINI COMPANION

One-time installation:
1. Open chrome://extensions in the browser where Gemini is logged in.
2. Enable Developer mode.
3. Click “Load unpacked”.
4. Select this gemini-extension folder.
5. Open https://gemini.google.com/app and keep the tab open while a post runs.

The companion talks only to http://127.0.0.1:3002 and only handles a pending
image job from the local content studio. It does not read passwords or cookies.
